「キビるフェスって、チラシで見かけたけど何のイベント？」

そう思った方、けっこういると思います。

キビるフェスは、福岡市内の音楽・演劇練習場を会場にした、冬の演劇祭です。

2027年版は**2026年12月18日（金）から2027年2月7日（日）まで**、仙台、大阪、名古屋、長崎、福岡の7団体が、市内の4会場で順番に上演します。

福岡にいながら、県外の劇団の作品もまとめて観られるお祭りなんですよ。

実は、私が制作広報をしている[福岡の劇団「万能グローブ ガラパゴスダイナモス」（通称ガラパ）](https://www.galapagos-dynamos.com/)も参加しています。

なので、ガラパも7団体のうちの1つとして、ほかの団体と同じように紹介していきますね。

この記事では、以下を順番に紹介します。

- キビるフェスがどんなお祭りなのか
- 2027年の7作品の日程と見どころ
- キビるフェスのおすすめどころ
- チケットの買い方と、2本目から安くなる「キビる割」
- 4つの会場の場所

演劇をあまり観たことがない方でも、読み終わるころには観たい1本が見つかるはずですよ。

## キビるフェスは、福岡の練習場が劇場になる冬の演劇祭

キビるフェス（正式名称は福岡きびる舞台芸術祭）は、福岡市にある4つの音楽・演劇練習場を会場に、各地の劇団の作品を上演する舞台芸術祭です。

名前の「きびる」は、福岡の方言で「結ぶ」「つなぐ」という意味です。

公式サイトでは「作り手や観客、舞台芸術に関わるすべての人へ向けて開催するお祭り」「人と土地を結び、未来へつなぐ橋渡し」と紹介されています。

始まったのは2017年2月で、2027年版は11回目にあたります。

2023年からはコンセプトを新しくして、作品の上演だけでなく、ワークショップなどの企画もあわせて開かれるようになりました。

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 福岡きびる舞台芸術祭 キビるフェス2027 |
| 会期 | 2026年12月18日（金）〜2027年2月7日（日） |
| 参加団体 | 7団体（仙台1、大阪2、名古屋1、長崎1、福岡2） |
| 会場 | 福岡市内の音楽・演劇練習場4か所 |
| 主催 | 4つの練習場の指定管理者、福岡市 |
| 共催 | 公益財団法人 福岡市文化芸術振興財団 |
| 企画制作 | アートマネージメントセンター福岡 |
| 公式サイト | [キビるフェス公式サイト](https://kibirufes-fuk.localinfo.jp/) |

2027年のテーマは「Reキビる」です。

これまでにキビるフェスで生まれた縁も、これからの縁もまとめてつないで届ける、という意味が込められています。

たとえば、仙台のMICHInoX（ミチノークス）は、前回のキビるフェス2026に続いて2年連続の参加ですよ。

## 7作品それぞれの見どころ

ここからは、7作品の中身を上演順に紹介していきますね。

あらすじや作品の説明は、キビるフェス公式サイトと各団体の公式サイトの内容をもとにしています。

### MICHInoX『ケモノヒト』（仙台）

MICHInoX（ミチノークス）は、2011年4月、東日本大震災の直後に仙台で結成された劇団です。

『ケモノヒト』は、およそ2万年前の氷河期の森を舞台にした冒険劇です。

父の仇を討つために「最強の狩人」を目指す少年が、北から来た謎の少女と出会い、運命が動き出していきます。

東北の歴史や風土を下敷きにした作品と、俳優の体から出る爆発力が持ち味の劇団なので、福岡の劇団ではなかなか観られないタイプの舞台ですよ。

- 日時：12月18日（金）19:00／19日（土）14:30、18:00／20日（日）13:00
- 料金：一般3,900円、U25 2,900円、U18 1,000円（全席自由）
- 初めて劇場で観劇する方は1,000円引き（18歳以下は無料）になる「初めてのカンゲキ割」あり（数量限定）

劇団のこれまでの作品や面白さは、[MICHInoX（ミチノークス）を紹介した記事](/blog/michinox)で詳しく書いています。

### 劇団ヒロシ軍『愛することで精一杯生きてるつもりでいたんだけど…』（長崎）

長崎の劇団ヒロシ軍は、人気作品を含む短編を数本まとめて上演します。

**上演する作品は回によって少しずつ違う**ので、1回だけ観るのはもちろん、何回か通っても楽しめる公演です。

公式サイトでは、長年連れ添った夫婦の『野菜炒め』、演劇あるあるで戦う『アーミー』、『ペットボトルナックル』シリーズなどが紹介されていますよ。

- 日時：12月26日（土）14:00、19:00／27日（日）11:00、15:00
- 27日11:00の回は、舞台手話通訳付きで上演されます
- 料金：一般前売2,500円（当日3,000円）、U-25 1,500円（当日2,000円）、未就学児無料（全席自由）

### INDEPENDENT『INDEPENDENT in キビるフェス』（大阪）

INDEPENDENTは、大阪で2001年から続いている一人芝居のフェスティバルです。

キビるフェスでは、約30分の一人芝居を3本続けて上演します（全体で約90分）。

上演するのは、九州で生まれたセリフ中心の2本と、大阪で生まれた体の動き中心の1本です。

| 作品 | 出演 | 初演 |
| --- | --- | --- |
| 『森田と林田』 | 大迫旭洋（プレグラ） | 2011年 |
| 『時間切れを待ちながら』 | 白濱隆次（謎のモダン館） | 2011年 |
| 『Psyche－プシュケ－』 | 和田雄太郎（脚本・演出は彗星マジックの勝山修平） | 2017年 |

3人の俳優の一人芝居を1回で観られるので、「どんな演劇が自分に合うのかわからない」という方にもおすすめですよ。

- 日時：1月15日（金）19:00／16日（土）11:30
- 料金：一般3,000円（当日も同じ）、U25 2,000円（前売のみ）、全席自由

俳優向けには、ワークショップ「俳優の名刺代わりになる一人芝居の創り方」も1月16日と17日に開かれます（2日間通しで一般10,000円、定員15名程度、応募は12月28日まで）。

### PUYEY『おんたろうズ〜それっぽい地図〜』（福岡）

PUYEY（プイエイ）は福岡のユニットで、今回は10周年記念公演、7年ぶりの福岡市での公演になります。

主人公は、人間のネガティブなエネルギーを軽くする神様の遣い「おんたろう」です。

人の心の「選択」に寄り添う「おんたろう」たちの、クスッと笑えてちょっぴり切ない物語で、「おんたろう」シリーズの最終章にあたります。

子どもと大人が一緒に楽しめる「わいわい鑑賞回」があるのも、この公演の特徴です。

わいわい鑑賞回は、未就学児も入場できて、上演中の入退場やおしゃべりもOKな回です。

客席は暗くならず、大きな音や強い光も控えめに調整されるので、小さなお子さんと一緒でも安心して観られますよ。

- 日時：1月15日（金）19:30／16日（土）11:00、15:00／17日（日）11:00、15:00（わいわい鑑賞回は16日11:00と17日15:00）
- 料金：一般3,500円、U25 2,000円、小学生500円（当日は各券500円増し、全席自由）
- 障がい者手帳をお持ちの方は各券500円引き
- 日英字幕付きの上演もあります（対象の回は団体の公式サイトで確認してください）

名古屋の劇団オイスターズの作・演出家である平塚直隆さんと、福岡の俳優8名が一緒に作ります。

## キビるフェスのおすすめどころは4つ

キビるフェスならではの楽しみ方は、以下の4つです。

- 福岡にいながら、県外の劇団を観られる
- 30分の一人芝居から長編まで、上演の形がいろいろ
- 2本目からは「キビる割」で安くなる
- 子ども連れや、耳が聞こえにくい方も観やすい回がある

それぞれ解説していきますね。

### 福岡にいながら、県外の劇団を観られる

7団体のうち5団体は、仙台、大阪、名古屋、長崎といった福岡の外を拠点にしています。

県外の劇団の公演を観に行くとなると、交通費や宿泊費もかかりますよね。

キビるフェスなら、福岡市内の会場で観られます。

MICHInoXの東北の歴史を題材にした舞台や、大阪の一人芝居フェスのように、ふだん福岡ではなかなか出会えない作品に触れられるのが一番の魅力です。

### 30分の一人芝居から長編まで、上演の形がいろいろ

キビるフェスの7作品は、上演の形もばらばらです。

| 上演の形 | 作品 |
| --- | --- |
| 1本の物語をじっくり観る | 『ケモノヒト』『おんたろうズ』『ドレミの歌』『キューピッツ』 |
| 約30分の一人芝居を3本 | 『INDEPENDENT in キビるフェス』 |
| 回ごとに変わる短編を数本 | 劇団ヒロシ軍の短編作品公演 |
| 3編のオムニバス | 『白日』 |

「2時間も集中して観られるかな…」と不安な方は、短い作品が続く公演から選ぶのもありですよ。

### 2本目からは「キビる割」で安くなる

キビるフェスには、2団体以上の公演を観るとお得になる「キビる割」があります。

ほかの参加団体の公演チケットの半券か、予約画面などを公演当日の受付で見せると、一般料金から割引されます。

| 割引額 | 対象の公演 |
| --- | --- |
| 500円引き | 劇団ヒロシ軍、PUYEY |
| 300円引き | MICHInoX、オイスターズ『ドレミの歌』、三等フランソワーズ、ガラパ |
| 200円引き | INDEPENDENT |

1本目のチケットの半券は、捨てずに取っておいてくださいね。

### 子ども連れや、耳が聞こえにくい方も観やすい回がある

キビるフェスでは、いろんな人が観に来られるように、鑑賞サポートのある公演がいくつかあります。

- 劇団ヒロシ軍：12月27日11:00の回は舞台手話通訳付き
- PUYEY：未就学児も入れる「わいわい鑑賞回」、日英字幕付きの上演、障がい者手帳割
- ガラパ：車椅子席、台本の事前貸し出し、衣装を音声で紹介する動画

サポートの内容は公演ごとに違うので、気になる方は各団体の公式サイトで確認してみてくださいね。

## よくある質問

### キビるフェスのチケットはどこで買えますか？

作品ごとに、各団体の公式サイトやローソンチケットなどで予約します。

キビるフェスの公式サイトでまとめて買う仕組みではありません。

7作品を1回ずつ観られる共通チケット（限定20枚）は、2026年11月10日に完売しています。

### 2本以上観るとお得になりますか？

はい、「キビる割」があります。

楽しめますよ。

観られる公演があります。

- 2026年12月18日から2027年2月7日まで、福岡市内の4会場で7作品を上演
