「演劇のお祭りみたいだけど、詳しくなくても行って大丈夫かな？」

そう思っている方、けっこういるんじゃないでしょうか。

キビるフェスは、演劇が好きな人はもちろん、これまであまり劇場に行ったことがない方でも気軽に楽しめる、福岡の冬の演劇祭です。

会場になるのは、福岡市内の音楽・演劇練習場。

2027年版は**2026年12月18日（金）から2027年2月7日（日）まで**、仙台、大阪、名古屋、長崎、福岡の7団体が、市内の4会場で順番に作品を上演します。

わざわざ県外へ遠征しなくても、福岡にいながら各地のいろんな劇団に出会える、冬ならではのぜいたくなお祭りなんですよ。

実は、私が制作広報をしている[福岡の劇団「万能グローブ ガラパゴスダイナモス」（通称ガラパ）](https://www.galapagos-dynamos.com/)も、この7団体のひとつとして参加しています。

自分の劇団だけ推したくなる気持ちをぐっと抑えて、ほかの6団体と同じ目線で紹介していきますね笑

この記事では、以下の5つを順番にお伝えします。

- キビるフェスがどんなお祭りなのか
- 2027年の7作品の日程と見どころ
- キビるフェスのおすすめどころ
- チケットの買い方と、2本目から安くなる「キビる割」
- 4つの会場の場所

読み終わるころには、「これ観に行ってみたいな」と思える1本がきっと見つかりますよ。

## ふだんの練習場が劇場に変わる、福岡の冬の演劇祭

キビるフェス（正式名称は福岡きびる舞台芸術祭）は、福岡市にある4つの音楽・演劇練習場を会場にして、各地の劇団の作品を上演する舞台芸術祭です。

名前の「きびる」は、福岡の方言で「結ぶ」「つなぐ」という意味。

公式サイトでも「作り手や観客、舞台芸術に関わるすべての人へ向けて開催するお祭り」「人と土地を結び、未来へつなぐ橋渡し」と紹介されています。

始まったのは2017年2月なので、2027年版は11回目にあたります。

2023年からはコンセプトを新しくして、作品の上演だけでなく、ワークショップなどの企画もあわせて開かれるようになりました。

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 福岡きびる舞台芸術祭 キビるフェス2027 |
| 会期 | 2026年12月18日（金）〜2027年2月7日（日） |
| 参加団体 | 7団体（仙台1、大阪2、名古屋1、長崎1、福岡2） |
| 会場 | 福岡市内の音楽・演劇練習場4か所 |
| 主催 | 4つの練習場の指定管理者、福岡市 |
| 共催 | 公益財団法人 福岡市文化芸術振興財団 |
| 企画制作 | アートマネージメントセンター福岡 |
| 公式サイト | [キビるフェス公式サイト](https://kibirufes-fuk.localinfo.jp/) |

2027年のテーマは「Reキビる」です。

これまでにキビるフェスで生まれた縁も、これからの縁も、まとめてつないで届けるという意味が込められています。

たとえば、仙台のMICHInoX（ミチノークス）は、前回のキビるフェス2026に続いて2年連続の参加なんですよ。

こうして縁がつながっていくのも、お祭りならではですよね。

![MICHInoX『ケモノヒト』のチラシ。骨のような化石と「ケモノヒト」の毛筆の題字](/blog-images/kibirufes-2027/flyers/kemonohito.jpg)

*『ケモノヒト』のチラシ（上の部分）*

トップバッターを飾るMICHInoX（ミチノークス）は、2011年4月、東日本大震災の直後に仙台で結成された劇団です。

父の仇を討つために「最強の狩人」を目指す少年が、北から来た謎の少女と出会い、運命が動き出していく冒険劇です。

東北の歴史や風土を下敷きにした世界観と、俳優の体から出る爆発力が持ち味の劇団なので、ふだん福岡で観る舞台とはまたひと味違う迫力を味わえますよ。

## 私がキビるフェスをおすすめしたい4つの理由

キビるフェスのおすすめどころは、以下の4つです。

- 福岡にいながら、県外の劇団を観られる
- 30分の一人芝居から長編まで、上演の形がいろいろ
- 2本目からは「キビる割」で安くなる
- 子ども連れや、耳が聞こえにくい方も観やすい回がある

それぞれ解説していきますね。

### 福岡にいながら、県外の劇団を観られる

今回参加する7団体のうち、5団体は仙台、大阪、名古屋、長崎と福岡の外を拠点にしています。

ふだん県外の劇団の公演を観に行こうとすると、どうしても交通費や宿泊費がかかりますよね。

でもキビるフェスなら、福岡市内の会場にふらっと出かけるだけで観られます。

MICHInoXの東北の歴史を題材にした舞台や、大阪の一人芝居フェスなど、いつもの福岡ではなかなか出会えない作品に触れられるのが一番の魅力です。

### 30分の一人芝居から長編まで、上演の形がいろいろ

7作品はジャンルだけでなく、上演の形もばらばらです。

| 上演の形 | 作品 |
| --- | --- |
| 1本の物語をじっくり観る | 『ケモノヒト』『おんたろうズ』『ドレミの歌』『キューピッツ』 |
| 約30分の一人芝居を3本 | 『INDEPENDENT in キビるフェス』 |
| 回ごとに変わる短編を数本 | 劇団ヒロシ軍の短編作品公演 |
| 3編のオムニバス | 『白日』 |

「2時間も座って集中できるかな…」とちょっと不安な方は、短い作品が続く公演から選んでみるのも全然ありですよ。

### 2本目からは「キビる割」で安くなる

1本観て「おもしろかった、もう1本観てみようかな」となったら、ぜひ使ってほしいのが「キビる割」です。

2団体以上の公演を観るとお得になる仕組みで、ほかの参加団体の公演チケットの半券か予約画面などを公演当日の受付で見せると、一般料金から割引されます。

| 割引額 | 対象の公演 |
| --- | --- |
| 500円引き | 劇団ヒロシ軍、PUYEY |
| 300円引き | MICHInoX、オイスターズ『ドレミの歌』、三等フランソワーズ、ガラパ |
| 200円引き | INDEPENDENT |

1本目のチケットの半券は、うっかり捨ててしまわないように取っておいてくださいね。

### 子ども連れや、耳が聞こえにくい方も観やすい回がある

いろんな方が安心して劇場に来られるように、鑑賞サポートが用意された公演がいくつかあるのもキビるフェスの良いところです。

- 劇団ヒロシ軍：12月27日11:00の回は舞台手話通訳付き
- PUYEY：未就学児も入れる「わいわい鑑賞回」、日英字幕付きの上演、障がい者手帳割
- ガラパ：車椅子席、台本の事前貸し出し、衣装を音声で紹介する動画

サポートの内容は公演ごとに違うので、気になる方は各団体の公式サイトをのぞいてみてくださいね。

## よくある質問

### キビるフェスのチケットはどこで買えますか？

作品ごとに、各団体の公式サイトやローソンチケットなどで予約します。

キビるフェスの公式サイトでまとめて買う仕組みではないので、観たい公演の窓口から申し込んでくださいね。

7作品を1回ずつ観られる共通チケット（限定20枚）は、2026年11月10日に完売しています。

### 2本以上観るとお得になりますか？

はい、「キビる割」が使えます！

ほかの参加団体の公演チケットの半券か予約画面を当日の受付で見せると、一般料金から200〜500円引きになりますよ。

### 演劇を観たことがなくても楽しめますか？

大丈夫、楽しめますよ。

MICHInoXには、初めて劇場で観劇する方が1,000円引き（18歳以下は無料）になる「初めてのカンゲキ割」（数量限定）も用意されています。

長い作品に集中できるか不安な方は、約30分の一人芝居が3本続くINDEPENDENTや、短編が続く劇団ヒロシ軍、3編のオムニバスの三等フランソワーズから選ぶのもおすすめですよ。

### 子ども連れでも観られますか？

観られる公演があります。

PUYEYの「わいわい鑑賞回」（1月16日11:00、17日15:00）は、未就学児も無料で入場できて、上演中の入退場やおしゃべりもOKです（保護者は有料）。

劇団ヒロシ軍も未就学児は無料で入場できます。

一方で、オイスターズ『ドレミの歌』、三等フランソワーズ『白日』、ガラパ『キューピッツ』は未就学児は入場できないので、予約の前に確認しておいてくださいね。

## 迷ったら、その日の気分で1本選んでみてください

ここまで、キビるフェス2027の7作品と楽しみ方を紹介してきました。

ポイントを振り返っておきますね。

- 2026年12月18日から2027年2月7日まで、福岡市内の4会場で7作品を上演
- 7団体のうち5団体は県外の劇団で、ふだん福岡ではなかなか観られない作品に出会える
- 2本目からは「キビる割」で200〜500円引き
- チケットは作品ごとに各団体で予約する

どれから観るか迷ったら、そのときの気分で選んでみるのが一番です。
