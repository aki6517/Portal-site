# 劇団向け 公演掲載マニュアル（はじめての方向け）

この手順書は、**このポータルサイトに自分の劇団の公演を掲載する方法**を、できるだけやさしくまとめたものです。  
パソコン操作が苦手な方でも、画面の表示どおりに進めれば登録できます。

## 1. まず準備するもの

1. ログインに使うメールアドレス（Googleアカウントでも可）
2. 公演チラシ画像（`jpg` / `png` / `webp`、**5MB以下**）
3. 表示用画像（トップや詳細で見せる画像、`jpg` / `png` / `webp`、5MB以下）
4. 公演情報メモ
   - 公演タイトル
   - 公演ページのURLに使う英字（例: `kemonohito`。決め方は「5. 公演ページのURLについて」）
   - 公演開始日時（1件以上）
   - カテゴリ（コメディ、会話劇など）
   - 料金（円。数字だけ）

## 2. ログインする

1. ブラウザで ` /register ` を開く  
   - 例: `https://あなたのドメイン/register`
2. 「**Googleでログイン**」または「**メールリンクでログイン**」を押す
3. ログイン後、「現在の状態」が**ログイン中**になっていることを確認する

## 3. 劇団情報を登録する（初回のみ）

1. ` /register ` の「**劇団情報の登録 / 追加**」まで下に進む
2. 次の項目を入力する
   - 劇団名
   - 連絡先メール
   - 公式サイトURL（任意）
   - 劇団紹介（任意）
3. 「**劇団情報を送信**」を押す
4. 「劇団を追加しました...」の表示が出たら完了

補足:
- 福岡アクトポータル運営が先に情報を載せている劇団と同じ名前で送ると、「この劇団は、福岡アクトポータル運営がすでに情報を載せています。…」と出て、その下に「**「劇団名」の引き継ぎを申し込む**」の欄が出ます。お名前と劇団での立場（例：主宰、制作）を入れて「**引き継ぎを申し込む**」を押してください。運営が確認してから、あなたのアカウントをその劇団の代表としてつなぎ、ご登録のメールアドレスにお知らせします（ふだんは数日以内）。名前を変えて別の劇団として登録し直す必要はありません
  - 申し込み中は、この画面の上に「『劇団名』の引き継ぎを申し込み中です（日付）。」と出ます。間違えたときは「申し込みを取り消す」で取り消せます
  - 申し込み中にできるのは3件までです
- 同じ名前の劇団に、もうメンバー（代表など）がいるときは「同じ名前の劇団がすでに登録されています。…」と出ます。その劇団のメンバーになりたい場合は、劇団の代表の方に、この画面の「メンバー管理」にある「ログイン可能メールを追加」から、あなたのメールアドレスを追加してもらってください
- 「福岡アクトポータル編集部（外部情報）」は運営用の名前のため使えません
- 登録した劇団は、すぐに公演を登録・公開できます。
- 運営が劇団の掲載を止めている場合などは、公演を「公開」にできません（「下書き」での保存はできます）。そのときは福岡アクトポータル運営にお問い合わせください。

## 4. 公演を新規登録する

1. ` /theater ` を開く
2. 「**新規公演を作成**」を押す
3. 画面上部の4ステップを順番に進める

### ステップ1: 画像

1. 「**チラシ画像（表面・公開ページに表示されます）**」を選んでアップロード
2. 裏面などがあれば「AI解析用チラシ画像（裏面など・任意）」もアップロード
3. 「**AI解析を実行**」を押す（自動入力される）
4. 必要なら「**表示用メイン画像（任意・トップや詳細で優先表示）**」もアップロード
5. 「次へ」を押す

### ステップ2: 基本

1. カテゴリを1つ以上選ぶ（複数可）
2. 「**公演ページのURLに使う英字（必須）**」を入力（例: `kemonohito`）
3. 「公演タイトル」を入力
4. 「次へ」を押す

注意:
- **最初に選んだカテゴリ**（「選択中」のいちばん左）が、公演ページのURLに使われます。  
  例: 最初に「ドラマ」を選び、英字を `kemonohito` にすると `/events/drama/kemonohito`
- 2つ目からのカテゴリは、カテゴリ別の一覧でこの公演を見つけてもらうためのものです。URLには使われません。
- 最初のカテゴリを変えたいときは、いったんチェックを外して、先にしたいカテゴリから選び直してください。
- 英字の決め方は、次の「5. 公演ページのURLについて」を見てください。

### ステップ3: 日程・会場

1. 「情報公開日時」（任意）を入力  
   - 未来日時を入れると、その時刻まで公開されません
2. 「公演開始日時（複数）」を**1件以上**入力
3. 必要に応じて会場名、住所、料金、販売所・予約窓口を入力
4. 「次へ」を押す

料金の入れ方:
- 金額は**円単位の整数**で、半角の数字だけを入れてください（例: `3000`）。
- 「,」や「円」を付けたり全角の数字で入れたりすると、金額が入りません。小数（例: `3000.5`）は保存できません。
- 券名を「一般」「学生」にした料金は、公演ページの一般料金・学生料金として表示されます。

### ステップ4: 詳細・公開

1. あらすじ、タグ、脚本、演出、キャストを入力（任意）
2. 「ステータス」を選ぶ
   - `公開`: 公開ページに表示
   - `下書き`: 一般公開しない
   - `非公開`: いったん公開した公演を引っ込めるときに使用
3. 「**公演を作成**」を押す
4. 「公演を作成しました。」が出たら保存完了

補足:
- 劇団の登録が承認済みでない場合（運営が掲載を止めている場合など）は、`公開` にできません。`下書き` で保存して、運営にお問い合わせください。

## 5. 公演ページのURLについて

公演ページのURLは `/events/（最初のカテゴリ）/（英字）` になります。英字は次のきまりで入れてください。

1. 使えるのは**英小文字（a〜z）・数字・ハイフン（-）**だけです
   - 大文字は使えません（`Kemonohito` ではなく `kemonohito`）
   - ハイフンは先頭・末尾には置けません。続けて2つ（`--`）も使えません
   - 80文字以内にしてください
2. **劇団の公式サイトや予約ページのURLは入れないでください**
   - それらは「販売所・予約窓口」の欄に入れてください
3. **ほかの公演が使っているURLは使えません**
   - 同じカテゴリで、ほかの公演がすでに同じ英字を使っていると保存できません
   - ほかの公演が**以前に使っていたURL**も使えません（検索やSNSに残っている、その公演へのリンクを守るためです）
4. **公開中の公演の英字（または最初のカテゴリ）を変えると、URLが変わります**
   - 前のURLを開いた人は、新しいURLへ自動で移ります
   - 下書き・非公開・情報公開日時の前の公演で変えた場合は、前のURLはまだ外に出ていないので、移る先は作られません
   - 自分の公演の前のURLに戻すことはできます

## 6. 公開を確認する

1. ` /theater ` に戻る
2. 作成した公演の行で「**公開ページ**」を押す
3. 公開ページで以下を確認する
   - 日時
   - 会場
   - 料金
   - 販売ページURL
   - 画像表示

## 7. いったん下書き・非公開にする方法

1. ` /theater ` で対象公演の「**編集**」を押す
2. 編集画面上部で状態を変更する
   - 「公開する」
   - 「非公開にする」
   - 「下書きに戻す」
3. 必要ならフォーム内の内容を直し、「変更を保存」

補足:
- 劇団の登録が承認済みでない場合は、「公開する」と、公開中の公演の「変更を保存」ができません。「非公開にする」「下書きに戻す」はできます。

## 8. 削除する方法（元に戻せません）

1. 公演の編集画面を開く
2. 下部の「**完全削除**」を押す
3. 確認ダイアログでOKすると削除完了

## 9. SNS宣伝文を作る方法（任意）

1. 公演を保存した後、編集フォーム下部の「SNS宣伝文生成」を開く
2. 対象SNS（twitter / instagram / facebook）にチェック
3. 「**宣伝文を生成する**」を押す
4. 「コピー」を押してSNS投稿に貼り付ける

補足:
- 宣伝文を作れるのは、その公演の劇団のメンバーだけです。

## 10. よくあるエラーと対処

1. 「公演ページのURLに使う英字と公演タイトルは必須です。」
   - 英字とタイトルが空です。両方入力してください。
2. 「公演開始日時を1つ以上入力してください。」
   - 日時が未入力です。最低1件追加してください。
3. 「カテゴリを1つ以上選択してください。」
   - カテゴリ未選択です。1つ以上チェックしてください。
4. 「ここには公式サイトなどのURLは入れられません。…」
   - 英字の欄にURLが入っています。公演名などを英小文字・数字・ハイフンで入れてください（例: `kemonohito`）。公式サイトのURLは「販売所・予約窓口」の欄へ。
5. 「英小文字（a〜z）・数字・ハイフン（-）だけで入力してください。…」
   - 大文字・日本語・記号・空白などが入っています。「5. 公演ページのURLについて」のきまりで入れ直してください。
6. 「80文字以内で入力してください。」
   - 英字が長すぎます。短くしてください。
7. 「このURL（英字）は、ほかの公演がすでに使っています。別の英字にしてください。」
   - 同じカテゴリで、ほかの公演が同じ英字を使っています。英字を変えてください（例: 後ろに年や会場を付ける）。
8. 「このURLは、ほかの公演の以前のURLとして使われているため使えません。別の英字にしてください。」
   - ほかの公演が以前に使っていたURLです。英字を変えてください。
9. 「料金は円単位の整数（例：3000）で入力してください。」
   - 金額に小数などが入っています。半角の数字だけで入れ直してください。
10. 「劇団の登録が承認済みではないため、公演を公開できません。…」
    - いまは公開できません。`下書き` で保存して、福岡アクトポータル運営にお問い合わせください。
11. 「同じ名前の劇団がすでに登録されています。…」
    - その劇団にはもうメンバーがいます。メンバーになりたい場合は、劇団の代表の方に「メンバー管理」の「ログイン可能メールを追加」からメールアドレスを追加してもらってください（「3. 劇団情報を登録する」の補足）。
    - 「この劇団は、福岡アクトポータル運営がすでに情報を載せています。…」と出たときは、下に出る「引き継ぎを申し込む」から申し込んでください。
12. 「…のアップロードに失敗しました: 画像は5MB以下にしてください。」
    - 画像サイズが大きすぎます。5MB以下にして再アップロードしてください。
13. 「…のアップロードに失敗しました: 画像は jpg・png・webp のどれかにしてください。」
    - 画像形式を `jpg/png/webp` に変換してください。

## 11. 迷ったときの最短ルート

1. ` /register ` でログイン
2. 劇団情報を送信
3. ` /theater ` で「新規公演を作成」
4. 必須4点だけ入力  
   - カテゴリ
   - 公演ページのURLに使う英字
   - タイトル
   - 公演開始日時
5. ステータスを「公開」にして保存

以上で掲載できます。まずは1件登録して、あとから編集で整える運用がおすすめです。
